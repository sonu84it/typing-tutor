# Typing Quest

A playful, browser-based typing tutor for beginners and kids.

## Practice journey

1. Key Garden — single home-row characters
2. Pattern Playground — character groups
3. Word Workshop — words
4. Sentence Safari — sentences
5. Story Summit — longer passages

Each chapter provides five practice variations and Easy, Medium, and Hard difficulty settings. Learners earn points for correct typing, lose points for mistakes, work against the clock, and can review incorrect characters in red after a round.

## Run locally

Open `index.html` in a browser, or serve this folder with a static web server.

## Publish with GitHub Pages

In the repository settings, choose **Pages**, select the `main` branch, and use the root folder as the publishing source.
